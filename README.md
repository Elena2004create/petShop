### PetShop

В директории `shop/server` запускаем сервер

```
cd /path/to/shop/server
npm install
npm run start-dev
```

В директории `shop/client` запускаем клиент

```
cd /path/to/shop/client
npm install
npm start
```


* Пользователь `user@gmail.com`, пароль `123`
